# Data

The introductory lesson uses the Iris flower dataset via
`sklearn.datasets.load_iris`. It is bundled with scikit-learn, so students do
not need to download or add a data file.

The dataset was introduced by Ronald A. Fisher in “The use of multiple
measurements in taxonomic problems” (1936) and is available from the
[UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris).
UCI lists the dataset under the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/).
The original measurements are in centimeters. The data are small, public,
non-personal, and included by scikit-learn for educational use.

For future lessons, document each dataset's source and license here. Do not
commit large datasets, private data, or data containing personally identifying
information. Put locally downloaded files in this directory only when their
license and size make redistribution appropriate.
